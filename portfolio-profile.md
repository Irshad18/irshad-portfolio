## 1. Build Prompt (copy-paste this into your AI code tool)

```
Build a single-page personal portfolio website using a dark bento-grid layout,
inspired by modern product-designer portfolios but adapted for a backend/automation
developer. Use React + Tailwind CSS (or plain HTML/CSS if simpler).

Design direction:
- Background: near-black (#0d1117), card backgrounds slightly lighter (#161b22)
- Text: off-white (#e6edf3) primary, muted grey (#8b949e) secondary
- Accent color: #3fb950 (terminal green) used sparingly — buttons, highlights, one icon
- Font: monospace for headings (JetBrains Mono / Fira Code), Inter for body text
- Rounded corners (rounded-2xl), soft grid gaps, no harsh borders

Layout — bento grid, single page, no scrolling animations, sections as grid cards:
1. Top nav bar: name + small dot logo, links to Work / Contact (right-aligned)
2. Hero card (large): "Hey, I'm [Name]" + role tagline + short location line
3. Photo card (medium): headshot or avatar placeholder
4. Stat cards (small, 2x2 grid): experience years, bots maintained, certifications —
   big number + label style, like "4+ / Years Experience"
5. Links card: GitHub, LinkedIn, personal domain — pill-style buttons
6. About card (wide): 3-4 sentence bio
7. Contact card (medium): "Have a project in mind?" + email button in accent color
8. Experience list card: role + company + duration, stacked rows
9. Footer: small text, last updated, domain link

Keep all cards responsive — stack to single column on mobile.
Do not add stock illustrations or unrelated icons — keep it text/data focused.
```
